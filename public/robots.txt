# NOTHING IS DISALLOWED HERE ANY MORE, AND THAT IS THE FIX RATHER THAN AN
# OVERSIGHT.
#
# This file used to Disallow /admin and the six placeholder routes, while
# netlify.toml sent `X-Robots-Tag: noindex` on those same paths. The two
# directives cancelled each other out. A compliant crawler does not fetch a
# Disallowed URL, so it never received the response carrying the noindex — the
# header was unreadable by design. The practical result is the opposite of what
# was intended: if any of those URLs is discovered from an external link (and
# this file itself publicly enumerated all seven), Google can index it as a
# URL-only result showing "No information is available for this page", and the
# only signal that would remove it sits behind the block.
#
# Crawling is now allowed everywhere so that the noindex headers can actually be
# read and obeyed. netlify.toml sends them on all seven paths, bare and globbed.
# Access control for /admin was never robots.txt's job and is unaffected: it is
# enforced server-side by Google sign-in plus an allowlist, verified in every
# /api/admin-* function.

# ---------------------------------------------------------------------------
# AI AND ANSWER-ENGINE CRAWLERS
#
# Named explicitly and allowed, deliberately.
#
# IFN's discovery problem is not that too many machines read the site — it is
# that answer engines could not read it at all. Until the prerender step landed,
# every URL returned an empty <div id="root">, and none of these agents execute
# JavaScript. Naming them and allowing them is the clearest available signal
# that this content is meant to be cited when someone asks an assistant "what
# founder communities are there in Austin" or "where do immigrant founders in
# the US find each other" — which is exactly the query this site should win.
#
# Google-Extended deserves a note because it is the one that is easy to get
# wrong: it does NOT affect Google Search ranking or crawling at all. It governs
# only whether content may be used to ground Gemini and AI Overviews responses.
# Disallowing it would remove IFN from AI Overviews while changing nothing about
# blue-link search, which would be a pure loss here.
# ---------------------------------------------------------------------------
